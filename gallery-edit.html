      ⚡ 제일 빠른 방법 — 셀렉 파일(.md) 가져오기 (자동 입력)
      

        이미 셀렉 .md 파일(사진마다 판정·DIR·사유가 표로 적힌 것)을 만들었다면, 하나하나 손으로 안 쳐도 돼요. 표를 통째로 붙여넣으면 폴더 전체가 한 번에 채워집니다.
        
    
          
  1. 맨 위 📋 셀렉 가져오기 클릭
    2. 
          
  2. 셀렉 .md 내용 전체를 복사 → 붙여넣기 (또는 📁 .md 파일 열기)
    3. 
          
  3. 미리보기에 “○장 인식 — core/support/hold/drop · 폴더 날짜”가 맞는지 확인
    4. 
          
  4. 가져오기 → 그 폴더 사진들에 판정·DIR·사유가 한 번에 채워져요
    5. 
        

        

          · 아이콘 변환: 🟢→core · 🟡→support · 🔴→drop · 📝(비고)→drop · ❓(보류)→hold

          · 목록에 없는 사진은 자동으로 등록돼요 — 모달의 ☑ 목록에 없는 사진은 자동 등록 체크(기본 켜짐)만 있으면, 사진을 따로 안 올려도 .md 하나로 그 폴더가 통째로 생성+판정·DIR·사유 완성. 셀렉 파일의 날짜(예: 2026/03/0316)로 그 폴더만 안전하게 채웁니다.

          · 원본문법은 DIR만 맞으면 갤러리에서 자동으로 떠요.

          · 가져온 뒤 ⬇ 다운로드 → GitHub 업로드해야 실제 반영돼요.

· 판정에 따라 다르게 안내 — 뽑은 사진(core·support)인데 DIR이 비었으면 ⚠ DIR 미입력(채우라고), 버린 사진(drop)의 코드 아닌 값(MIRROR 기각 등)은 ✎ 기각 메모로 표시돼요(오류 아님, 정상). 통계칩 ⚠ DIR없음(뽑음)으로 채울 사진만 모아볼 수 있어요.
· 아래엔 원본 데이터(JSON)도 보여요(전체 확인용). 닫을 땐 × 또는 Esc.
· 맨 아래 🗑 이 사진 삭제로 목록에서 뺄 수 있어요. (R2 이미지는 안 지워지고 목록에서만 빠져요. 다운로드→GitHub 업로드해야 실제 반영.)

      🔎 사진을 누르면 오른쪽에 뜨는 입력칸·“코드”가 뭐예요?
      

        사진을 누르면 오른쪽 패널 위쪽에 셀렉 사유·DIR 입력칸(직접 쓰고 💾 저장), 그 아래에 원본 데이터(JSON)가 글자(코드) 형태로 떠요(전체 확인용). 각 줄 뜻은 이래요:
        
    
          
  • id — 사진 이름(파일명)
    • 
          
  • filename — 사진의 실제 인터넷 주소(R2)
    • 
          
  • verdict — 판정 (core·support·hold·drop)
    • 
          
  • dir — 분류(폴더·DIR 코드)
    • 
          
  • reason — 판정 이유(설명 글)
    • 
          
  • author — 글쓴이 (K/P). 없으면 K예요.
