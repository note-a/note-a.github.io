📖 사용설명서 — 갤러리 판정 입력기

    
이 도구는 촬영한 사진 6천여 장을 하나씩 보면서 판정(core·support·hold·drop)을 매기는 곳이에요. 프로그램 설치·코딩 필요 없이 클릭 → 다운로드 → GitHub에 올리기 3단계면 끝. 처음이어도 아래 순서대로만 하면 됩니다.


    
🗺 화면 구성 (어디에 뭐가 있나요)
      
    
        
  • 맨 윗줄 — 왼쪽에 제목·현재 상태, 오른쪽에 ❓사용법 ↻라이브 로드 📁파일 열기 ⬇다운로드 버튼.
    • 
        
  • 둘째 줄(도구 막대) — 작업자(K/P) · 검색칸 · 판정·시트·글쓴이 고르기 · + 사진 추가.
    • 
        
  • 셋째 줄(통계 칩) — 전체·core·support·hold·drop·K·P 개수. 칩을 누르면 그 종류만 모아서 볼 수 있어요.
    • 
        
  • 가운데 — 사진 카드들. 카드 아래마다 CORE·SUP·HOLD·DROP 버튼, 좌상단에 누가 정했는지 K/P 뱃지.
    • 
      

    


    
1
먼저 “내가 누구인지” 고르기 (작업자)
도구 막대 왼쪽 작업자에서 K 또는 P를 누르세요. 지금부터 내가 매기는 판정이 그 사람 이름으로 기록됩니다. 
※ 지금까지 된 작업은 전부 K로 되어 있어요.

    
2
볼 사진 고르기 (모아 보기)
· 통계 칩을 누르면 그것만 모여요. 예) hold 칩을 누르면 아직 못 정한 보류 사진만 나와요. 한 번 더 누르면 전체로 돌아가요.
· 검색칸에 파일명·폴더·이유를 적으면 그것만 나와요.
· 판정·시트·글쓴이 고르기로도 좁힐 수 있어요.

    
3
판정 매기기
사진 아래 CORE · SUP · HOLD · DROP 중 하나를 누르면 그 판정이 됩니다(고른 건 검게 채워짐). 사진 좌상단에 내 이름(K/P) 뱃지가 붙어요.

    
4
사진 자세히 보기 (선택 사항)
사진의 이미지·글자 부분(버튼 말고)을 누르면 오른쪽에 그 사진의 원본 데이터가 떠요. 닫을 땐 × 또는 Esc 키.

    
5
저장하기 — 이걸 해야 실제로 반영돼요!
판정을 바꾸면 맨 위에 “● 수정됨”이 떠요. 아직은 내 화면(브라우저)에만 있는 상태예요.
① 오른쪽 위 ⬇ 다운로드를 누르면 admin-contents.json 파일이 컴퓨터에 받아져요.
② github.com/note-a/note-a.github.io 접속 → 그 저장소의 admin-contents.json을 연 뒤 → Add file ▸ Upload files 화면에 방금 받은 파일을 끌어다 놓아요 → 아래 Commit changes 클릭.
③ 1~2분 뒤 실제 갤러리에 반영됩니다.


    
⚠️ 꼭 기억할 점
      
    
        
  • 목록 파일은 note-a.github.io repo(= 실제 사이트가 있는 곳)에 업로드해요. 사진 이미지는 여기 올리지 않아요(용량 큼) — 이미지는 Cloudflare R2에만.
    • 
        
  • 수정 내용은 다운로드→업로드 전까지 내 브라우저에만 있습니다. 새로고침하면 사라져요.
    •

      core 핵심 채택
      support 보조
      hold 보류
      drop 기각
    


    

      🔎 사진을 누르면 오른쪽에 뜨는 “코드”가 뭐예요?
      

        사진의 이미지·글자 부분(판정 버튼 말고)을 누르면 오른쪽에 그 사진의 원본 데이터가 글자(코드) 형태로 떠요. 그냥 확인용이라 여기서 직접 고칠 필요는 없어요. 각 줄 뜻은 이래요:
        
    
          
  • id — 사진 이름(파일명)
    • 
          
  • filename — 사진의 실제 인터넷 주소(R2)
    • 
          
  • verdict — 판정 (core·support·hold·drop)
    • 
          
  • dir — 분류(폴더·DIR 코드)
    • 
          
  • reason — 판정 이유(설명 글)
    • 
          
  • author — 글쓴이 (K/P). 없으면 K예요.
    • 
        

      

    


    

      📷 새 사진 등록하는 법
      

        ⚠️ 사진 파일(이미지)은 GitHub에 올리지 않아요. 용량이 커서 GitHub엔 못 올립니다.

        · 이미지 → Cloudflare R2에만 올려요.

        · GitHub → 목록 파일(admin-contents.json)만 올려요. (사진 “주소”만 적힌 작은 텍스트 파일)
      

      
A
이미지는 Cloudflare R2에 올리기
날짜 폴더 규칙대로 업로드 → 연도/월/월일/파일명.jpg
예: 2026/03/0316/DSCF1234.jpg · 썸네일(/t/)은 R2가 자동 생성해요.
📤 R2 버킷(set-photos) 열기 ↗

      
B
목록에 등록 — 한 장이든 여러 장이든
상단 + 사진 등록 → 시트 · 날짜 폴더 · 판정을 고르고, 파일명을 한 줄에 하나씩 붙여넣으세요(한 장이면 한 줄만). R2 주소가 자동으로 만들어져 전부 한 번에 추가돼요. 기본 판정은 hold(보류) 추천, 확장자 빠뜨리면 .jpg 자동.

      
C
저장
⬇ 다운로드 → GitHub(note-a.github.io) 업로드(위 5번과 동일). GitHub엔 이 목록 파일만 올라가요.

      

        ❗ 파일명은 R2에 실제로 올린 파일과 “똑같이” 적어야 해요 (대소문자·확장자 포함). 편집기는 주소만 만들 뿐 사진이 진짜 있는지 확인하지 않아요 — 이름이 틀리면 갤러리에서 깨진 이미지로 나와요.
👉 순서: ① R2에 사진 먼저 올리기 → ② 그 파일명 그대로 등록.
      

      

        💡 팁 — 사진이 많으면 Claude에게 맡기기

        직접 하나씩 붙여넣기 번거로우면, 날짜 폴더 + 파일명 목록(또는 “8001~8100” 같은 범위)만 Claude에게 주세요. admin-contents.json에 전부 등록해 완성 파일로 돌려줘요 — 그럼 GitHub에 올리기만 하면 끝. (사진 이미지는 R2에 먼저 올려둬야 해요.)
